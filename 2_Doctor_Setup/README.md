# Doctor Cabinet Setup Guide (PC, Laptop & Mobile)

This folder contains the launchers to set up doctor devices (PCs, Laptops, and Mobiles/Tablets) to run the **Doctor Consultation Console** (patient history, prescriptions, visit summaries).

---

## 1. Computer / Laptop Setup (Under 2 Minutes)
1. Ensure the computer/laptop is connected to the same Wi-Fi router as the Host Server.
2. Double-click the file `launch_pc_doctor.bat`.
3. On the first run, enter the Central Server Host IP Address (e.g. `192.168.1.5`) when prompted.
4. The doctor console will instantly load in your default browser.
5. (To change the server IP, delete the generated `server_config.txt` file and run it again).

---

## 2. Mobile / Tablet Setup (Under 1 Minute)
1. Double-click `launch_mobile_doctor.html` on your PC or Laptop.
2. Enter the Central Server Host IP Address and click **Generate QR Code**.
3. Connect your mobile phone or tablet to the **same clinic Wi-Fi**.
4. Open the camera app on your phone/tablet and scan the QR code displayed on the screen.
5. The Doctor Consultation Console will load instantly on your phone/tablet.
