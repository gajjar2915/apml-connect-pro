# 💧 APML Connect Pro - Enterprise EMR & Clinical Suite

> **State-of-the-Art Electronic Medical Records (EMR), Offline-First Mesh Sync & Liquid UI Design System**

Welcome to **APML Connect Pro**, a comprehensive, multi-workstation clinical management solution designed for modern healthcare environments. It connects Receptionists, Doctors, and Pharmacists into a unified, high-performance ecosystem with 100% operational uptime guarantee.

---

## 🚀 Quick Start (1-Click Launching)

To launch the complete APML Connect Pro ecosystem instantly:

1. **Double-click** `START_APML_CONNECT_PRO.bat` in the root folder.
2. The system automatically launches all microservices and opens the **Unified 3-Section Switchable Liquid Login Portal** in your default browser.

Or open the standalone portal directly:

## 💡 Key Features Highlight

1. **Liquid UI Design System**: Fluid Glassmorphism translucent cards (`backdrop-filter: blur(20px)`), dynamic floating gradient background canvas, glowing neon focus halos, and springy interactive micro-animations.
2. **Unified 3-Section Switchable Portal**: Single tabbed login page seamlessly switching between Receptionist, Doctor, and Pharmacy roles with color theme morphing.
3. **Offline-First Mesh Sync (`meshSync`)**: Autonomous peer-to-peer data synchronization protocol ensuring zero data loss during network outages.
4. **Drag & Drop Lab Report Uploader**: Receptionists can drag PDF/image test reports directly into patient profiles with instant doctor sync.
5. **Doctor Instant Patient Search Bar**: Real-time name/ID search bar in the Doctor console loading full medical history, vitals, prescriptions, and lab reports in 1 click.
