✚ APML Connect Pro

Complete Installation, Deployment & Operations Guide
Official Setup Manual v1.0
Note: APML Connect Pro is a containerized multi-terminal SaaS healthcare platform designed to run seamless local Wi-Fi peer-to-peer sync across clinic desktops, laptops, iPads, and mobile devices.

Phase 1: System Requirements & Prerequisites

  • Central Host Server PC: Windows 10/11 (64-bit), 8 GB RAM minimum (16 GB recommended), 10 GB free storage.
  • Prerequisite Software: Docker Desktop for Windows (with WSL 2 Backend enabled).
  • Network Requirements: Local Wi-Fi Router or LAN connection connecting host server and client workstations.

Step 1: Install & Verify Docker Desktop

  1. Download Docker Desktop from https://www.docker.com/products/docker-desktop/
  2. Run Docker Desktop Installer.exe and check the box "Use WSL 2 instead of Hyper-V".
  3. Restart your computer when installation completes.
  4. Launch Docker Desktop and wait until the whale icon in the system tray turns solid green.

Phase 2: Windows Firewall Configuration (Required for Wi-Fi Network Access)

To enable other laptops, iPads, and mobile devices on your Wi-Fi network to connect to this server:

  1. Open Start Menu & Search for "Windows Defender Firewall with Advanced Security".
  2. Click Inbound Rules in the left pane → Click New Rule... in the right pane.
  3. Select Port → Click Next → Select TCP.
  4. In Specific local ports, enter: 3001, 3002, 3003, 5005 → Click Next.
  5. Select Allow the connection → Keep Domain, Private, Public checked → Click Next.
  6. Name the rule APML Connect Pro Server → Click Finish.

Phase 3: Central Server Launch & Deployment

  1. Open Command Prompt or PowerShell in the setup directory: 
    cd d:\parvg\OneDrive\Desktop\reception\0_Server_Host_Setup
  2. Run the automated container build command: 
    docker compose up -d --build
  3. Verify all 6 container services are online and healthy: 
    docker ps
Container Name Service Component Port / URL
apml-connect-receptionist Reception Desk Front-End http://localhost:3001
apml-connect-doctor Doctor Cabinet EMR Workstation http://localhost:3002
apml-connect-pharmacy Pharmacy Counter Desk http://localhost:3003
apml-connect-backend Node.js API & WebSockets http://localhost:5005
apml-connect-db PostgreSQL 15 Database Port 5432
apml-connect-redis Redis 7 Memory Cache Port 6379

Phase 4: Workstation Launchers & Wi-Fi Client Connection

1. On the Central Server Computer:

Double-click the desktop / root launcher icons or open direct URLs in your web browser:

  • Doctor Cabinet: Double click Launch Doctor Cabinet.exe or open http://localhost:3002
  • Reception Desk: Double click Launch Receptionist.exe or open http://localhost:3001
  • Pharmacy Counter: Double click Launch Pharmacy Counter.exe or open http://localhost:3003

2. On Other Laptops / iPads / Phones over Local Wi-Fi:

  1. Find the Host IP address by running ipconfig in terminal (e.g. 192.168.1.5).
  2. Open browser on any client device and go to:
    • Doctor Workstation: http://<HOST_IP>:3002/dashboard/doctor
    • Reception Desk: http://<HOST_IP>:3001/dashboard/reception
    • Pharmacy Desk: http://<HOST_IP>:3003/dashboard/pharmacy

Phase 6: Daily Maintenance Commands

  • Start Server Stack: docker compose up -d
  • Stop Server Stack: docker compose stop
  • View Server Logs: docker compose logs -f
  • Hard Refresh Browser Cache: Press Ctrl + Shift + R
