# Receptionist Desk Setup Guide (Computer & Mobile)

This folder contains the launchers to set up receptionist devices (Computers and Mobiles/Tablets) to run the **OPD Receptionist Dashboard** (patient registration, queues, billing).

---

## 1. Computer / Laptop Setup (Under 2 Minutes)
1. Ensure the computer is connected to the same Wi-Fi router as the Host Server.
2. Double-click the file `launch_pc_reception.bat`.
3. On the first run, enter the Central Server Host IP Address (e.g. `192.168.1.5`) when prompted.
4. The dashboard will instantly load in your default browser.
5. (To change the server IP, delete the generated `server_config.txt` file and run it again).

---

## 2. Mobile / Tablet Setup (Under 1 Minute)
1. Double-click `launch_mobile_reception.html` on your computer.
2. Enter the Central Server Host IP Address and click **Generate QR Code**.
3. Connect your mobile phone or tablet to the **same clinic Wi-Fi**.
4. Open the camera app on your phone/tablet and scan the QR code displayed on the computer screen.
5. The Receptionist Mobile Console will load instantly on your phone/tablet.
